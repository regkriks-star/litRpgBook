# Библиотека изображений

Для поиска рисунка открыть [каталог](catalog.md): там перечислены все зарегистрированные игровые изображения, содержание листов, кадры, использование и ограничения. Рабочий реестр — [src/assets.ts](../../src/assets.ts), общие правила опор — [sprite-registration.md](../guides/sprite-registration.md).

## Где что хранится

| Путь от корня | Назначение |
| --- | --- |
| `public/art/characters/` | Общие листы персонажей и противников по именам; не копировать между главами. |
| `public/art/locations/` | Фоны мест: Фиол, пустошь, Гильдия, луга, дорога, ворота и река Тантрума. |
| `public/art/cards/` | Рисунки карт классов и даров. |
| `public/art/illustrations/prologue/` | Семь цельных иллюстраций пролога. |
| `docs/art/catalog.md` | Человеческое описание игровых ресурсов. |
| `docs/art/sources/chapter-NN/` | Соглашение для новых пакетов генерации: паспорт, промпты, исходники. Каталог создавать при появлении ресурсов. |
| `docs/art/sources/shared-<тема>/` | Новые пакеты общих наборов, например предметов. |

Общий предметный тайлсет `meadowItems` создан; паспорт и промпт — [shared-items](sources/shared-items/README.md). Инвентарь, добыча и счётчик используют одни растровые кадры. Для нового тайлсета использовать общий лист, прозрачный фон и стабильные ID. Названия, количество и рамки выводить интерфейсом.

Исторические исходники оставлены по прежним путям, чтобы сохранить происхождение генераций. Они не входят в сборку. Старое имя `exec-…png` само по себе не объясняет содержание; искать соответствие в паспорте пакета и смотреть рисунок. Если точное соответствие не записано, отметить это и сверить перед повторным использованием.

## Подключение и проверка

Новый WebP положить в подходящий раздел `public/art/`, зарегистрировать стабильный ID, фактический размер и сетку или прямоугольники. Главы используют `assetUrl(id)`, который учитывает BASE_URL и вложенное размещение. Смена кадров управляется сценой; используется неподвижный WebP с прозрачностью, а не встроенная анимация файла.

Конвертация не меняет размеры и прозрачные поля; наличие регулярной сетки в промпте не гарантирует её на рисунке. У Датарис метаданные в `src/dataris-poses.ts`, у Мача и NPC главы 2 — в `src/ChapterTwoArt.tsx`. Масштаб определяется телом и опорами, не границей вытянутой руки. Регистрация мозаики нового тела — в `src/HeroCreation.tsx`.

При добавлении ресурса обновить каталог и паспорт исходников: содержание, кадры, направления, сцены, промпт, ограничения. `npm run check:art` проверяет наличие файлов, дубли, размеры и сетки. Визуально проверить фактическую нарезку, опоры, маршрут и мобильный размер для изменённых ресурсов. Документы и исходные PNG не помещать в `public/`.
