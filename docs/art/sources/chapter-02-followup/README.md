До промптов закреплён маршрут: Мач идёт к городу, повозка догоняет его сзади, затем везёт к воротам; после высадки едет внутрь без него. Новая эмоциональная поза сохраняет этот маршрут. На холме герой поднимается слева направо, после гребня сбегает к стоящей перед водой толпе; нижняя часть viewport занята текстовым окном. Контрольные кадры проверяются в обычном размере на 568 × 320, без необходимости смотреть анимацию.

Исходные прозрачные PNG сохранены без изменения; WebP — формат доставки с сохранением альфа-канала, качество 94. Все рисунки без слов, рамок, цифр и интерфейса. Очертания поз размечены в `src/ChapterTwoArt.tsx`; документация не служит альтернативным источником координат.
