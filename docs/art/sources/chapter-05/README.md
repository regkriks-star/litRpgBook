Масштаб и опоры заданы один раз в метаданных и одинаковы при обычном/reduced motion просмотре, Назад и reload. Прозрачность проверяется численно и в реальной сцене: ненулевой alpha на фоне вокруг некоторых фигур потребовал дополнительной очистки встроенным imagegen. Кадр прозрачных рук использует `handsClip`: соседний ботинок лежачей позы заходит в левую часть прямоугольника и исключён общей маской. Метаданные и текущий игровой WebP важнее формулировок промпта. Новые предметы будущих глав не добавлены. Не зеркалить кадры с оружием и руками без проверки деталей.
