Один кадр переиспользуется в инвентаре, добыче и обмене. Дубинка, нож, одежда, целые фрукты, санка и ядра взяты из `townItems`/`meadowItems`; повторно не генерировались. Предметы следующей главы заранее не выдаются.

ImageMagick использован только для конвертации в WebP и выравнивания размеров листов до целых ячеек; художественное содержание создано `image_gen`. Исходные PNG не изменены. Промпты описывают пожелания, фактическую нарезку и направления определяют проверенные изображения и код. Итог события сохраняется при reduced motion; навигация не ждёт завершения анимации.
