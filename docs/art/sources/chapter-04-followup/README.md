# Дополнительные ресурсы главы 4

Созданы 05.10.2026 встроенным `image_gen` для явно запрошенных улучшений уровня 2. Перед генерацией прочитана вся глава 4, проверены финал главы 3, продолжение дуэльного эпизода и существующий каталог. Постановка всех мест использования записана в [повторной проверке](../../../reviews/chapter-04-followup.md). Генерация использовала старые пейзажи и `tavernCast` как ориентиры стиля и внешности; существующие ресурсы не заменялись.

| ID / игровой файл | Исходник / промпт | Содержание, использование и ограничения |
| --- | --- | --- |
| `ichiroVillageRoad`, `locations/ichiro-village-road.webp` | [road.png](road.png), 1536 × 1024; [промпт](road-prompt.txt) | Промежуточный участок дороги, деревня впереди слева, Тантрум далеко позади справа. Глава 4, 20–22. Повозка `ichiroFamily` идёт влево, пассажиры не отражаются; 17–19 остаются на исходной дороге, 23 показывает двор. Пейзаж без персонажей. |
| `tantrumDayMeadow`, `locations/tantrum-day-meadow.webp` | [meadow.png](meadow.png), 1536 × 1024; [промпт](meadow-prompt.txt) | Луговые холмы между деревней слева и Тантрумом справа. Глава 4, 33–38; герой слева бьёт вправо, кролик справа. Места встречи и готовые кадры кроликов различаются, маршрут к городу сохраняется. Без нарисованных героев и животных. |
| `tavernService`, `characters/tantrum/tavern-service.webp` | [service.png](service.png), 1254 × 1254; [промпт](service-prompt.txt) | Прозрачный лист 2 × 2 по 627: 0 трактирщик наполняет кружку из бочонка; 1 тот же трактирщик выставляет полную кружку справа; 2 взрослая пара с кружками; 3 новая взрослая пара у стойки. 48–50 и 75–84 — позы 0/1; взрослые 2/3 появляются только на 75–84. Молодёжь 48–50 взята из готового `tavernCast`. |

Исходный запрос сервиса предусматривал 1536 × 1536, но генератор вернул 1254 × 1254. Используется фактическая сетка 627, без растяжения до желаемого размера. Реальные опоры стоп и масштаб записаны в `tavernServiceFrames` в [ChapterFourArt.tsx](../../../../src/ChapterFourArt.tsx); прямоугольники не определяют масштаб фигуры. Непрозрачные части находятся внутри своих ячеек, кружки и бочонок не обрезаны. Стопы двух поз трактирщика зарегистрированы на одной сценической опоре, персонаж не сдвигается из-за вытянутой руки.

При reduced motion выводится поза 1 с уже поданной кружкой, посетители сохраняются в своих конечных точках. Волшебница остаётся у выхода справа; новый лист не содержит её, героя, Мими или баронета. Конфликт с 85 продолжает использовать исходные сюжетные группы.

Игровые WebP получены ImageMagick только конвертацией формата с качеством 90; содержимое и настоящий alpha-канал сохранены. PNG и промпты остаются в документации, не входят в публичную библиотеку билда.
