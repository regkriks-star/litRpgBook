# Боевые иллюстрации

Созданы встроенным `image_gen.imagegen`; CLI и внешние ключи не использовались.

Готовые ассеты:

- `public/art/characters/mach/battle.webp`: боевая стойка, замах, удар топором, завершение удара.
- `public/art/characters/sayaka/battle.webp`: стойка, заряд посоха, электрический болт, отдача.
- `public/art/characters/scorpion/battle.webp`: готовность, подготовка жала, выпад, возврат.
- `public/art/locations/guild.webp`: заключительная сцена у регистраторши Гильдии.

Каждый боевой лист — 2172×724 RGBA, четыре равных кадра 543×724, направление героев вправо и скорпиона влево. Исходники сохранены здесь в `*-sheet.png`. Прозрачность сохранена при кодировании WebP с качеством 90. Кадры меняются через CSS `steps(1)`; отдельные движения корпуса и подсветка удара синхронизированы с состояниями XState. При системном `prefers-reduced-motion` остаётся статичная стойка.

Промпты первоначального рисунка: `prompts.json`. Уточняющий промпт разделения кадров героев: `layout-edit-prompt.txt`. Промпт финальной сцены: `guild-prompt.txt`. Референсами служили существующие `companions.webp` и `scorpion.webp`, поэтому одежда, оружие и стиль сохранены.
