# Направление изменений

Сцена занимает весь экран. В диалогах крупные персонажи и наложенное снизу окно с именем говорящего; в бою отряд слева, враги справа, полосы прямо под фигурами. Полынь #799474, глубокий зелёный #23392f, свет слоновой кости #f7f7f2, бирюзовый #6f9ea7 и охра #b99a59 сохраняют живописный мир существующих иллюстраций. Alegreya — повествование, Golos Text — команды. Убрана структура страницы сайта с отдельными шапкой, карточками и подвалом.

Эпизод: полные абзацы 0–25 начала главы 8 локального FB2, до «Х… хорошо…» регистраторши. Номера считаются с нуля. Слова и пунктуация сохранены; авторские вставки вынесены в отдельные кадры. Длинное повествование разбивается по предложениям, без сокращений. Числовые параметры второго боя и три завершающих удара — игровая адаптация: книга не сообщает их точную последовательность.

Мобильная сцена предназначена для горизонтального положения. Манифест запрашивает landscape; API блокировки применяется там, где разрешён браузером. В остальных случаях портретный экран предлагает повернуть телефон. Это ограничение браузеров, включая iOS: https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock .

PWA предзагружает готовые файлы эпизода, иллюстрации и локальные шрифты. Service worker активируется только в production. Автообновление при следующем запуске, без принудительного перезапуска текущей игры. Документация: https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers .
