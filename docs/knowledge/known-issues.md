## Статусы

| Статус | Значение |
| --- | --- |
| `open` | Воспроизводится, не взято в работу |
| `in-progress` | Взято в работу; укажи дату и ветку/коммит |
| `fixed` | Исправлено; обязательны дата и ссылка на проверку |
| `wontfix` | Осознанно не исправляем; обязательна причина |
| `superseded` | Заменено другой записью; обязательна ссылка |

Правила: ID не переиспользуется; закрытая запись не удаляется; при исправлении добавляется проверка, а не только «готово».

## KI-001. Нет рабочего Git

**Уровень.** High · **Статус.** open · **Обновлено.** 2026-11-20

**Симптом.** `.git` — пустой каталог; `.local-history.git/config` указывает на `worktree = /home/makap/MyProjects/litRpg`; обычный `git status`/`git log` падает.

**Доказательство.** [Аудит, находка 1](../reviews/project-audit-2026-11-20.md#1-репозиторий-без-рабочего-git-high). Обход `git --git-dir=.local-history.git --work-tree="$PWD"` показывает один коммит `9101006`.

**Следующий шаг.** Инициализировать репозиторий от текущего состояния, настроить remote, сделать первый коммит; старую историю сохранить отдельно.

**Проверка.** `git status`, `git log --oneline`, успешный push/pull.

## KI-002. Dev-редактор без аутентификации

**Уровень.** Medium · **Статус.** fixed · **Обновлено.** 2026-11-20

**Симптом.** `npm run dev` слушает `0.0.0.0`; POST `/__scene-editor/chapter-0N.json` перезаписывает `src/scenes/*.json`. Проверка `Origin` не защищает запросы без `Origin`.

**Доказательство.** [vite.config.ts](../../vite.config.ts#L7-L20), [package.json](../../package.json#L7), [Аудит, находка 2](../reviews/project-audit-2026-11-20.md#2-dev-редактор-запись-без-аутентификации-medium).

**Что сделано.** Dev-сервер слушает `127.0.0.1`; для сети есть отдельный `dev:lan`. POST без `Origin` или с чужим `Origin` получает 403, с верным — проходит проверку.

**Проверка.** POST с чужим/пустым `Origin` отклоняется; редактор на localhost работает.

## KI-003. Зоны касания в главе 8 и модальных окнах

**Уровень.** Medium · **Статус.** fixed · **Обновлено.** 2026-11-20

**Симптом.** При 568 × 320 кнопки шапки и закрытия модального окна — 38 × 36, основная кнопка — 40 px. Требуется 44 × 44.

**Доказательство.** [styles.css](../../src/styles.css#L20), [styles.css](../../src/styles.css#L228-L231), [Аудит, находка 3](../reviews/project-audit-2026-11-20.md#3-мобильные-зоны-касания-меньше-44--44-medium).

**Что сделано.** Все важные кнопки главы 8 и модальных окон измерены на 568 × 320: 44 × 44, основная кнопка — 44 px по высоте.

**Проверка.** `getBoundingClientRect` всех важных кнопок на 568 × 320; касание по координатам.

## KI-004. Тяжёлая мобильная загрузка и PWA-кэш

**Уровень.** Medium · **Статус.** open · **Обновлено.** 2026-11-20

**Симптом.** WebP до 828 КБ, нет `srcset`; service worker прекеширует 104 файла / 31 МБ; `cache.addAll` атомарен.

**Доказательство.** [App.tsx](../../src/App.tsx#L216), [assets.ts](../../src/assets.ts), `dist/sw.js`; [Аудит, находка 4](../reviews/project-audit-2026-11-20.md#4-тяжёлая-мобильная-загрузка-и-офлайн-кэш-medium).

**Следующий шаг.** Уменьшенные варианты + `srcset`; выборочный precache (оболочка + текущая/следующая глава). Сначала измерить первый запуск.

**Проверка.** Размер сети на 568 × 320, установка PWA, офлайн-переход между частями.

## KI-005. `check:art` требует ImageMagick

**Уровень.** Medium · **Статус.** fixed · **Обновлено.** 2026-11-20

**Симптом.** `execFileSync('identify')` падает с `ENOENT` без ImageMagick; prerequisite нет в README.

**Доказательство.** [check-art.ts](../../scripts/check-art.ts#L16), [README.md](../../README.md#проверки), [Аудит, находка 5](../reviews/project-audit-2026-11-20.md#5-checkart-и-воспроизводимость-окружения-medium).

**Что сделано.** `check:art` читает размеры WebP собственным парсером RIFF/VP8/VP8L/VP8X и больше не вызывает ImageMagick.

**Проверка.** `npm run check:art` на чистой машине без ImageMagick.
