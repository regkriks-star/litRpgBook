# Настройки чтения

Общий компонент для всех книжных сцен: кнопка в toolbar, панель с тремя ползунками и сохранение выбора. Подключён в прологе, главах 1–5 и фрагменте главы 8. Новые главы используют его без копирования разметки.

## Файлы

| Файл | Назначение |
| --- | --- |
| `src/ReaderSettings.tsx` | Кнопка 44 × 44, панель, состояние, сохранение и клавиатура |
| `src/reader-settings.css` | Панель, общая геометрия окна и базовые размеры шрифта по поверхностям |
| `src/styles.css` | Фон `.story-window` использует `--reader-window-alpha` |
| `tests/reader-settings.spec.ts` | Сквозная проверка всех глав и телефона 568 × 320 |

Ключ `lazy-courage:reader-settings:v1` общий для книги: значение `{ font, window, transparency }`, запись появляется только после изменения. Диапазоны: шрифт 80–140 %, высота окна 80–120 %, прозрачность фона 0–65 %. Ширина окна не меняется ползунком. Настройки применяются через переменные на `<html>`:

* `--reader-font-scale` — множитель шрифта;
* `--reader-window-scale` — множитель высоты окна (ширина остаётся базовой);
* `--reader-window-alpha` — непрозрачность фона (1 — исходный вид).

## Как подключить новую главу

1. Импортировать `ReaderSettings` и поставить кнопку в toolbar рядом с «Оглавлением» и сбросом главы:
   ```tsx
   import ReaderSettings from './ReaderSettings';
   <ReaderSettings />
   ```
   В главе 8 кнопка стоит в `<nav aria-label="Меню игры">` рядом с игровыми настройками.
2. Добавить `reader-surface` к корневому `<main>` (или к `.app`):
   ```tsx
   <main className="stage prologue-reader reader-surface chapter-six">
   ```
3. Использовать стандартные классы окна и текста: `.story-window` и `.dialogue-text`. Правила компонента сами центрируют окно и меняют его высоту; ширина задаётся базовой переменной поверхности.
4. Если у новой поверхности другая геометрия, задать только базовые переменные в `src/reader-settings.css`, не переписывая `left/right/width/height`:
   ```css
   .reader-surface .story-window.chapter-six-reading {
     --reader-window-width: 92%;
     --reader-window-height: var(--reading-height);
     --reader-window-min: 0px;
   }
   ```
   Базовый шрифт задаётся через `--reader-font-base`; для низких экранов значение меняется в существующем `@media (max-height: 600px)`.
5. Не добавлять собственные `font-size` для `.dialogue-text` и не задавать окну фиксированные `height/min-height` поверх общих переменных: иначе ползунки перестанут действовать.
6. Проверить 1440 × 900, 1280 × 600, 1024 × 600, 844 × 390 и 568 × 320: панель внутри экрана, ползунки не меньше 44 px, «Сбросить настройки» достижима, значения переживают перезагрузку, при 100/100/0 окно совпадает с исходным.

## Редактор сцен

Предпросмотр редактора рендерит настоящую главу, поэтому кнопка и панель доступны и в предпросмотре, и в игре. Header исключён из объектов сцены (`SceneScope id="excluded-game-header"`), поэтому настройки не попадают в JSON постановки и не мешают расстановке. Настройки общие для всех глав, а не хранятся в `chapter-0N.json`.

## Перенос в другой проект

Скопировать `ReaderSettings.tsx`, `reader-settings.css` и строку фона из `.story-window` в `styles.css`; сохранить классы `.story-window`/`.dialogue-text` и `#root` (или заменить селектор `#root` на корень приложения). Ключ хранения можно оставить общим или заменить на имя проекта, чтобы настройки не пересекались.
