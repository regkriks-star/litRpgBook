# Редактор сцен

Открывается кнопкой **«Редактор сцен» в оглавлении**. Доступны главы 1–5. Кадр соответствует одному шагу чтения; номера в интерфейсе начинаются с 1, `paragraph` в JSON — с 0. Для абзацев с действиями список «Состояние» позволяет выбрать начало или результат каждого последовательного действия.

## Размещение

Список объектов находится слева от рабочей области; параметры выбранного объекта и комментарий к кадру — справа. Панели прокручиваются независимо. Компактные кнопки копирования, вставки, удаления, отражений, примагничивания и переключателей предпросмотра показывают подсказку при наведении и имеют доступные названия.

Нажмите на объект или выберите его в списке слева. Перетащите мышью/касанием; стрелки сдвигают на 1 пиксель предпросмотра, Shift — на 10. В правой панели свойств доступны масштаб, отражение по обеим осям, копирование, вставка, удаление и восстановление. Кнопка «Копировать» и вставка по Ctrl+V работают внутри текущего кадра, включая его состояния, где присутствует исходный объект. Буфер сохраняет размещение на момент копирования. Ctrl+C или Ctrl+Z отменяют последнее действие; кнопка со стрелкой отмены находится в верхней панели рядом с выбором состояния. Ctrl+Shift+Z возвращает отменённое изменение. В текстовых полях Ctrl+C сохраняет обычное копирование текста. «Удалить» скрывает объект, «Восстановить» возвращает его. Копия кнопки выполняет исходное действие с общим игровым состоянием; награда не выдаётся повторно.

Клик по персонажу выбирает его сценическую опору целиком. Список показывает вложенность отступами и соединительными линиями: родитель расположен над своими слоями и отмечен значком и подписью «Группа». Вложенные слои можно выбрать отдельно в списке. Цельные рисунки (например, Датарис с троном или люди в повозке) сохраняют исходную регистрацию; редактор не разрезает готовый рисунок на новые персонажи.

«Предыдущие спрайты» накладывает предыдущий кадр с прозрачностью 28%. «Примагнитить» совмещает выбранный объект с его опорой в предыдущем кадре, переносит размер и отражение, затем фиксирует. «Отмагнитить» сохраняет результат и разрешает свободное перемещение. Это снимок размещения только для текущего кадра: дальнейшие изменения соседних кадров не наследуются. Для сравнения используется последнее просмотренное состояние предыдущего кадра, иначе его начало.

## Предпросмотр

«Окно текста» скрывает нижнее окно только в редакторе. «Анимации» включает исходную постановку; без него показан итоговый неподвижный кадр. «Проверить действия» позволяет выполнять действия настоящими игровыми кнопками. Предпросмотр не записывает место чтения, инвентарь и другие игровые сохранения.

Телефонные размеры 568 × 320 и 844 × 390 создают настоящий горизонтальный viewport, включая media queries. Общее размещение используется и на телефоне, пока для объекта не создана мобильная поправка. Изменение в телефонном режиме задаёт такую поправку; «Использовать общее размещение» удаляет её. Мобильная поправка общая для всех горизонтальных телефонов.

Комментарий относится к целому кадру, сохраняется вместе со всеми его состояниями и показывается только в редакторе. В нём можно описывать будущую перегенерацию сцены.

## Сохранение и файлы

«Сохранить главу» всегда скачивает один JSON со всеми кадрами главы и сохраняет постановку для игры в текущем браузере. При локальном запуске через `npm run dev` дополнительно записывается `src/scenes/chapter-0N.json`. В опубликованном статическом приложении браузер не может переписать файлы сервера: скачанный JSON следует перенести в эту папку проекта для включения в следующую публикацию. Между устройствами постановку можно переносить через «Открыть JSON» и последующее сохранение.

Книжный текст остаётся в `src/chapter-*.json`, игровые правила — в существующих компонентах и редьюсерах. `src/scenes/chapter-01.json` … `chapter-05.json` содержат постановку: `defaults`, полный массив `frames`, `comment`, состояния `variants`, преобразования `elements` и ссылки копий `clones`.

В `elements` перечислены стабильные ID объектов каждого кадра, включая его состояния действий. Значение `null` означает общие исходные параметры из `defaults`; отредактированный объект содержит собственные преобразования, признаки удаления и фиксации. Так исходная расстановка не дублируется тысячами одинаковых записей.

Преобразования задают дополнение к исходной адаптивной сцене: `x`/`y` — смещение в процентах viewport, `scale` — множитель, `flipX`/`flipY` — отражения. Координаты атласов и исходная анимация сохраняются. Состояния действий наследуют размещение `start` в пределах одного абзаца; явная правка состояния перекрывает его. Между абзацами наследования нет. Объекты получают стабильные ID из `SceneObject` и `SceneScope`, повторяющиеся элементы — из `instanceKey`; эти ID нельзя менять при обычной переработке JSX.

Вставка сейчас ограничена объектами выбранного кадра. Общая библиотека ресурсов запланирована отдельно.
